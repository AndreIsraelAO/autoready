How it works

Three steps, and the last one is up to AutoReady.

1

Queue up

Hit Find match in your game, like always.

2

Step away

Grab a drink. AutoReady keeps an eye on the game.

3

Come back in time

It clicks Accept and lets you know with a sound, a Windows notification or your phone.

Built to be safe

It only does one thing, and it stays out of your way.

Never clicks mid-match

Your Steam status and Valve's official Game State Integration tell it when you're playing.

Doesn't touch the game

No memory reading, no injection, no modified game files. It just presses Accept, like you would.

No accounts or tracking

No ads, no analytics, open source. Installs for your user, no admin rights.

Questions

Can I get banned for this?

AutoReady only looks at the game window and presses Accept. It doesn't read or change game memory or files. Steam's terms do mention automation software, so the risk isn't zero, but nothing here touches the match itself.

Windows shows a SmartScreen warning

AutoReady is new and not code-signed yet (it's in progress). Click More info, then Run anyway.

Can I use it to stay AFK?

No, please don't. It's there so you don't miss a match while you grab something. Accept, then come back: leaving hurts the other nine players.

How do I uninstall it?

Settings → Apps → Installed apps → AutoReady → Uninstall. It removes everything it added.
