AutoReady

League of Legends auto accept

Queue up, step away, and AutoReady accepts your League match for you. Free and open source.

Download AutoReady for Windows

Windows 10 and 11. No admin rights needed.

How it works in League of Legends

  1. Install AutoReady and queue up as usual. There's nothing to set up.
  2. When the match is found, AutoReady accepts it through the League client's local API on your PC, without touching your mouse.
  3. It rings, shows a Windows notification and, if you want, pings your phone so you're back for champ select.

Is it safe?

  • It does nothing in champ select or in game, and it doesn't read game memory or change game files.
  • It uses the client's local API, the same one community tools have used for years. Riot doesn't officially document it, so it's a gray area (and not allowed in Korea). Details in the FAQ.
  • No accounts, ads or telemetry. Source code on GitHub.

Auto aceptar partida de League of Legends

Buscá partida, alejate y AutoReady acepta tu partida de League por vos. Gratis y de código abierto.

Descargar AutoReady para Windows

Windows 10 y 11. No pide permisos de administrador.

Cómo funciona en League of Legends

  1. Instalá AutoReady y buscá partida como siempre. No hay nada que configurar.
  2. Cuando se encuentra la partida, AutoReady la acepta por la API local del cliente de League en tu PC, sin tocar el mouse.
  3. Suena, muestra una notificación de Windows y, si querés, te avisa al celular para que vuelvas a la selección de campeón.

¿Es seguro?

  • No hace nada en la selección de campeón ni en partida, y no lee la memoria del juego ni cambia archivos del juego.
  • Usa la API local del cliente, la misma que usan herramientas de la comunidad hace años. Riot no la documenta oficialmente, así que es una zona gris (y no está permitido en Corea). Detalles en las preguntas frecuentes.
  • Sin cuentas, ni anuncios, ni telemetría. Código fuente en GitHub.
